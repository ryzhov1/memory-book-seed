# Иван Николаевич Очкин (1902)

- Привязка: Городищенский р-н, Лопатино — по именному списку 726 сп; в донесении 395 сд — «с. Лакутья» (села с таким названием в районе по известным источникам нет; возможно искажение — не утверждается). **Обе версии места рождения.** См. [[lopatino]].
- Карточка pamyat-naroda `person-hero121203842` (5 документов); ОБД id 51620768, 63604064.
- Красноармеец, стрелок [[726-sp-395-sd|726-го стрелкового полка 395-й стрелковой дивизии]]; призван 18.09.1941 Городищенским РВК (ЦАМО ф.7380 оп.383931с д.6). Полевая почта в рукописном списке 726 сп — 48481.

- **Расхождение дат:** свидетельство о болезни — ЭГ 3215, дата выбытия «03.1943» (поле-сводка, документ без скана) vs пропал без вести 23.07.1942. Обе версии записаны, не разрешено.
